# Соцмережі та генерація контенту

Рій приймає публічні URL, RSS і дозволені офіційні API. Для кожного матеріалу він зберігає URL, тип джерела, час отримання, короткий preview і статус. Аналітик не має вигадувати факти: результат повинен містити джерела та позначку `requires_human_review`.

## Підтриманий безпечний базовий режим

`agents/social_sources.py` читає відкриті HTTP(S)-ресурси без входу. Це підходить для RSS, YouTube feed URL та публічних вебсторінок, якщо їхні правила дозволяють такий доступ. Налаштування джерел знаходиться в `social-sources.json`.

## Офіційні API

YouTube Data API дозволяє шукати публічні відео, канали та плейлисти, але використовує квоти: <https://developers.google.com/youtube/data>.

X API дає доступ до публічних постів і аналітики, але працює за pay-per-use, тому його не слід обіцяти як безкоштовний: <https://docs.x.com/x-api/introduction>.

Telegram Bot API не є універсальним читачем усіх каналів. Бот бачить лише дозволений йому контекст, тому приватні чати та обхід доступу не підтримуються: <https://core.telegram.org/bots/api>.

## Генерація

`agents/content_pipeline.py` створює чернетку `artifacts/generated-content.json` із темою, коротким текстом, доказами та URL. Значення `AI_PROVIDER=demo` не виконує зовнішніх AI-викликів. Для live-моделі потрібен server-side адаптер і секрет у GitHub Actions або серверній платформі; секрет ніколи не потрапляє в JavaScript.
