
## Конкуренти, персональний бриф і медіа

У блоці **Конкурентний scan** можна додати відкриті HTTPS-URL конкурентів. Рій використовує їх лише як дослідницькі сигнали: структуру, навігацію, типи блоків і публічні CTA. Він не обходить вхід, CAPTCHA, paywall або `robots.txt` і не копіює чужі тексти, логотипи чи медіа. У **Персональному брифі** можна вказати аудиторію, пропозицію, тональність і потрібні правки; не додавайте паролі, токени, платіжні дані або чужі приватні дані.

**Фото та відео** можна додати з пристрою через file picker. У demo вони залишаються локальними та не завантажуються на сервер автоматично. Публічний URL із соціальної мережі додається в чергу тільки після підтвердження прав на використання. Production-імпорт із соцмереж має виконуватися окремим server-side адаптером через офіційний API.

У редакторі доступні **Імпортувати код** для `.html`, `.css`, `.js`, `.txt` і **Вивантажити HTML**, що зберігає поточну чернетку як `site-draft.html`. Перед публікацією перевірте ліцензії assets, секрети та SEO.
