# KROK Agent Swarm

Публічний прототип рою агентів для сайту KROK. Фронтенд працює як статичний сайт, а GitHub Actions перевіряє код і публікує його на GitHub Pages.

## Локальний запуск

```bash
python3 -m http.server 3000 --bind 0.0.0.0
```

Після цього відкрийте `http://localhost:3000`.

## Як працює рій

Панель приймає просту команду та показує послідовність: диспетчер → дослідник → аналітик → розробник → перевіряльник → видавець. У поточному MVP браузерний режим є безпечною демонстрацією і не виконує зовнішніх AI-запитів.

Живий режим має запускатися серверним workflow. Дослідник повинен отримувати лише відкриті вебсторінки, RSS та дозволені офіційні API. Заборонені приватні сторінки, обхід входу, CAPTCHA, paywall, robots.txt і збір чутливих персональних даних.

## GitHub Pages

У репозиторії відкрийте **Settings → Pages**, виберіть **GitHub Actions** як Source. Після push у `main` workflow `Validate and publish KROK Agent Swarm` перевірить файли і опублікує сайт. Посилання з’явиться у вкладці **Actions** та в **Settings → Pages**.

## Secrets

Не вставляйте ключі у HTML, JavaScript, коміти або журнали. Для живого AI-адаптера використовуйте GitHub Actions Secrets, наприклад `GEMINI_API_KEY` або інший ключ провайдера, і підключайте його тільки на серверному етапі. Безкоштовні тарифи мають ліміти та можуть змінювати умови.
