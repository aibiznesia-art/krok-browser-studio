# KROK Browser Studio

KROK Browser Studio — односторінкова браузерна робоча область для демонстрації керування Agent Swarm. Вона містить редактор HTML, timeline взаємодії шести ролей і sandboxed live preview.

## Локальний запуск

```bash
python3 -m http.server 3000 --bind 0.0.0.0
```

Відкрийте `http://localhost:3000`.

## Безпека GitHub

Фронтенд не містить і не зберігає GitHub-токени. Кнопка GitHub Pages пояснює безпечний server-side workflow. Реальна публікація довільних правок має виконуватися через GitHub Actions або окремий серверний GitHub OAuth/GitHub App endpoint, який перевіряє результат перед поверненням URL. Токени зберігаються тільки в GitHub Actions Secrets або секретному сховищі серверної платформи.

## Workflows

`pages.yml` перевіряє наявність HTML, сканує файли на типові секрети та публікує корінь репозиторію через GitHub Pages. `generated-content-pages.yml` запускається вручну або щопонеділка, читає лише налаштовані публічні URL/RSS/офіційні API, створює `generated/latest-content.json`, зберігає його артефактом і деплоїть сайт.

## Політика джерел

Дозволені лише відкриті вебсторінки, RSS і офіційні API. Заборонені приватні сторінки, обхід входу, CAPTCHA, paywall, robots.txt, збір чутливих персональних даних і публікація в соціальні мережі. Кожен результат має URL, час отримання, факти та прапорець `human_review_required`.

## Free-tier

Demo не викликає AI-провайдера, тому не витрачає модельні кредити. Для майбутнього live AI-адаптера секрети мають бути server-side; безкоштовні тарифи можуть мати денні ліміти, обмеження швидкості та змінні умови.
