# KROK Agent Swarm — план реалізації

## Мета
Перетворити наданий односторінковий сайт KROK на публічний тестовий проєкт із панеллю рою агентів. Користувач пише простий запит українською, а система показує послідовність роботи агентів, джерела, результати та стан публікації.

## Підхід
Перший етап — безпечний статичний фронтенд і GitHub Actions. Інтерфейс працює на GitHub Pages. Оркестрація запускається через workflow вручну або за розкладом, а секрети зберігаються лише в GitHub Actions Secrets. Модулі агентів мають незалежні адаптери, тому можна підключати free-tier провайдери без зміни UI.

## Рій агентів
- **Диспетчер:** розбирає коротку команду та створює план.
- **Дослідник:** читає лише відкриті URL, RSS і дозволені публічні API; не обходить авторизацію, CAPTCHA, paywall чи robots.txt.
- **Аналітик:** нормалізує результати, вказує джерела, час отримання та рівень упевненості.
- **Розробник:** готує зміни у файлах сайту лише після явного завдання.
- **Перевіряльник:** запускає синтаксичні, безпекові та збиральні перевірки.
- **Видавець:** створює артефакт, комітить зміни та повертає URL GitHub Pages.

## Дизайн
Наслідуємо наданий стиль **dark editorial tech**: глибокий винний фон, рожево-червоний акцент, скляні картки, Fira Code для технічних статусів і Plus Jakarta Sans для основного тексту. Інтерфейс рою — компактний control-room поверх портфоліо: командний рядок, стрічка агентів, картки джерел і чіткі стани без декоративного шуму.

## Структура
- `index.html` — наданий сайт-портфоліо з вбудованою панеллю рою.
- `swarm-ui.js` — клієнтський інтерфейс і демонстраційний режим без секретів.
- `agents/` — Python-скрипти оркестрації та роботи з відкритими джерелами.
- `.github/workflows/pages.yml` — перевірка та публікація на GitHub Pages.
- `public/manus-routes.json` — маніфест маршруту для Webdev.
- `.env.example` — назви секретів без значень.
- `README.md` — запуск, підключення secrets і правила безпеки.

## Обмеження
Безкоштовні моделі мають ліміти, можуть потребувати власний API-ключ і не гарантують постійну доступність. Ключі не потрапляють у HTML/JavaScript. Збір із соцмереж обмежується публічними сторінками, RSS та офіційними API згідно з правилами кожної платформи.
