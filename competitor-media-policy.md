# Конкурентні сайти та медіа

## Дозволений режим

Рій може працювати з відкритими сторінками конкурентів, які користувач має право досліджувати: URL має бути публічним, без входу, CAPTCHA, paywall або обходу `robots.txt`. Система бере лише структурні сигнали та відкритий контент для порівняння: навігацію, заголовки, типи блоків, публічні CTA, кольорові та контентні патерни. Не копіюйте тексти, логотипи, зображення, відео чи персональні дані без дозволу. Результат має бути оригінальним сайтом із власним брендом і правками.

## Персональний бриф

До брифу додавайте тільки інформацію, яку маєте право використовувати. Не вставляйте паролі, токени, платіжні дані, приватні контакти чи чутливі персональні дані. Рій використовує бриф для структури, тональності, аудиторії та пропозиції, але перед публікацією потрібна людська перевірка.

## Фото та відео

Локальні фото й відео можна додати через браузерний file picker; у demo вони залишаються локальними та отримують object URL для preview. Публічні URL із соціальних мереж можна додати в чергу лише після підтвердження прав на використання. Автоматичне завантаження з приватних профілів, обхід API, CAPTCHA, paywall або rate limits заборонені. Для production потрібен server-side адаптер із офіційним API та перевіркою ліцензії/дозволу.

## Імпорт та експорт коду

Імпорт у Studio підтримує текстові `.html`, `.css`, `.js` та `.txt` файли. Експорт завантажує поточний HTML як `site-draft.html`. Перед публікацією перевіряйте код, секрети, ліцензії сторонніх assets і SEO.
